# zenmon 0.8.0

Find the moment a value changed and share just the relevant recording.

- **Offline investigation:** press `F2` to jump to a receiver time, search
  payloads and attachments, or find the next/previous change at a JSON pointer.
  Searches run off the UI thread and can be cancelled.
- **Focused recordings:** narrow offline input with `--key`, `--since`, and
  `--until`. Export a standalone NDJSON recording with `trace export`, or mark
  an interval inside the dashboard and export the selected key or all keys.
  Original payload and attachment bytes are preserved.
- **Faster inspection:** unchanged detail views reuse rendered cells; message
  history snippets are formatted on demand. Rendering caches are bounded.
- **Recorded walkthrough:** the README now shows time navigation and a field
  change search using synthetic data, with commands to reproduce it locally.

Existing v1/v2 captures remain readable. Offline inspection opens no Zenoh
session. Search operates within the loaded selection and does not wrap.
Exports refuse to overwrite existing files; set both interval marks explicitly.
