# zenmon 0.9.0

Resume an offline investigation where you left it, and follow recorded changes
without repeatedly typing commands.

- **Investigation checkpoints:** the offline viewer saves the message position,
  selected key, filter, expanded branches, plots, diff setting, last search and
  interval marks locally. Reopening resumes paused at 1×. Five-second background
  checkpoints and normal-exit saves never modify the source recording.
- **Content-aware restoration:** SHA-256 fingerprints cover the entire validated
  source and the loaded selection during indexing. Changed recordings or selected
  windows start fresh. Corrupt or future-version state is reported and preserved.
  Use `--no-resume` to bypass both restoration and writes, or
  `ZENMON_TUI_STATE_DIR` to choose the local state directory.
- **Faster navigation:** Tab completes offline commands and payload/attachment
  field paths, arrow keys recall session command history, and F3/F4 repeat the
  last search forward/backward while preserving its original key scope.
- **Local playback:** Space starts/pauses playback; F9/F10 choose 0.25×–4× speed.
  Playback respects receiver-time gaps, pauses for inspection, and stops at the
  end. No messages are sent to the network; publishing remains `zenmon replay`.

Existing capture formats remain compatible. Local checkpoints contain key names,
filters and the last search argument, but no captured payloads. Command history
and pinned payload baselines are not saved. See the offline dashboard section
in `docs/usage.md` for storage locations, limits and reset instructions.
